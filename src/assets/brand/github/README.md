# GitHub 公式ロゴ（Invertocat）

https://brand.github.com/GitHub_Logos.zip の中の Invertocat（黒）の SVG を、**中身を編集せずに** このフォルダへ置く。

- ファイル名は任意（`*.svg` を1つだけ置く）。`src/lib/architecture.ts` が `?url&no-inline` で読み込み、構成図の白いタイルに `<image>` で表示する
- 色・パス・余白を変えない。`currentColor` に置き換えない
- ファイルが無いあいだは、汎用アイコン（Material Symbols の `code`）で表示する
